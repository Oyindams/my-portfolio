Landslide Detection Using Satellite Imagery

Comparative analysis of traditional ML vs. deep learning on 12-channel multi-modal satellite imagery.

Final year thesis benchmarking traditional ML against deep learning for binary landslide detection, using the Zindi Africa Landslide Detection dataset — ~7,160 labelled (64×64×12) patches fusing Sentinel-2 optical bands with Sentinel-1 SAR radar, enabling detection under all weather conditions including cloud cover.

0.889F1-Score (XGBoost, best)
98.6%AUC-ROC
96.2%Accuracy
5Models Compared

Best model: tuned XGBoost (F1 0.889) — outperforming a custom 12-channel CNN and EfficientNetV2B0 transfer learning, confirming that well-tuned gradient boosting is more data-efficient than deep learning at this dataset scale (~7K samples). Explainability via SHAP (TreeExplainer) and LIME on the CNN.
